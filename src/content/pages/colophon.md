Flagrant System Error is curated from the following tools:

- [Notion](http://notion.so) - a general purpose workspace for “notes, tasks, wikis, and databases.”

- [Next.js Notion Starter Kit](https://nextjs-notion-starter-kit.transitivebullsh.it) - a website generator that sources pages from Notion.

- Keynote - presentation software included with macOS



Notion is available on almost any platform, and it provides a consistent interface to creating content.

Next.js Notion Starter Kit is easily configured to read a website from Notion and display it with React and Next.js.

Keynote is used for creating diagrams used within posts. It’s not the primary function of the software, but it does a serviceable job and doesn’t require additional software.
